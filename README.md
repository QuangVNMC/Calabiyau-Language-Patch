# Calabiyau Language Patch
A quick vibe coded Strinova language extractor in Python to use in CalabiYau  
# How da fuck CalabiYau use Strinova language file ???
In the game code, it load the localization from "Localization" folder (duh). But it doesn't exist in CalabiYau, so the simple way is extract localization from Strinova and paste into that so the game will load it before it download the Chinese localization  
# Ok, how do i apply this ?
Download (or extract) the language file, copy the Localization folder to CalabiyauGame\PM\Content and you pretty much done
